# Almacenamiento

Los dispositivos de almacenamiento conservan archivos y programas incluso al apagar el ordenador.

## HDD frente a SSD
| Característica | HDD | SSD |
|---|---|---|
| Tecnología | Platos magnéticos | Memoria flash |
| Partes móviles | Sí | No |
| Velocidad | Generalmente menor | Generalmente mayor |
| Coste por GB | Habitualmente menor | Habitualmente mayor |
| Uso común | Archivos y copias | Sistema y aplicaciones |

## Interfaces
- **SATA:** interfaz utilizada por HDD y SSD SATA.
- **NVMe:** protocolo de almacenamiento de alta velocidad sobre PCIe.
- **M.2:** formato de módulo; no todos los M.2 tienen necesariamente la misma interfaz.

## Almacenamiento en red y externo
- **Disco externo:** conectado normalmente por USB.
- **NAS:** comparte archivos en una red.
- **SAN:** proporciona almacenamiento por bloques a servidores mediante una red especializada.
- **Óptico y cinta:** CD, DVD, Blu-ray o cinta para usos específicos y archivo.

```text
Disco del sistema sin conectar → puede no encontrarse
un dispositivo desde el que arrancar.
```

> [!NOTE]
> RAM y almacenamiento no son lo mismo: la RAM es temporal y el HDD/SSD conserva los datos.

**Repaso:** ¿Qué tecnología tiene platos giratorios? **El HDD.**

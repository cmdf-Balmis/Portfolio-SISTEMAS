# Tipos de redes y topologías

Una **red informática** conecta dispositivos para intercambiar información y compartir recursos.

## Tipos según su alcance
| Tipo | Cobertura | Ejemplo |
|---|---|---|
| PAN | Personal | Bluetooth entre móvil y auriculares |
| LAN | Local | Red de un aula |
| MAN | Metropolitana | Redes dentro de una ciudad |
| WAN | Grandes distancias | Internet |

También pueden ser **públicas, privadas o semipúblicas** y utilizar medios **cableados o inalámbricos**.

## Topologías
| Topología | Descripción | Riesgo o ventaja |
|---|---|---|
| Estrella | Equipos conectados a un nodo central | Sencilla, depende del nodo central |
| Anillo | Forman un circuito | Flujo organizado, posibles interrupciones |
| Bus | Comparten un canal | Económica, sensible a problemas del canal |
| Malla | Muchos enlaces entre nodos | Redundancia, coste elevado |
| Árbol | Organización jerárquica | Escalable |
| Híbrida | Mezcla varias topologías | Flexible |

```text
ESTRELLA:
PC1 ─┐
PC2 ─┼─ SWITCH ─ ROUTER
PC3 ─┘
```

> [!NOTE]
> «Topología física» describe conexiones materiales; «topología lógica» describe cómo circula la información.

**Repaso:** ¿Qué topología usa un nodo central? **Estrella.**

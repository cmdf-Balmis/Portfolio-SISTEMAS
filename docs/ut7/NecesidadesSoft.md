# Necesidades de software según el entorno productivo

No todas las empresas requieren los mismos programas. Antes de elegir software se deben analizar **función, coste, requisitos, compatibilidad, seguridad y soporte**.

## Ejemplos de sectores
| Entorno | Necesidad | Software posible |
|---|---|---|
| Oficina | Informes y hojas de cálculo | Suite ofimática |
| Industria | Diseño técnico | CAD |
| Comercio | Ventas e inventario | TPV |
| Empresa de servicios | Gestión de clientes | CRM |
| Desarrollo | Programar y probar aplicaciones | IDE, Git |

## Coste total
El coste no es solo el precio inicial: también incluye **licencias**, suscripciones, instalación, formación, soporte, mantenimiento y migración.

## Requisitos y comprobaciones
- **Hardware:** CPU, RAM, espacio y GPU si hace falta.
- **Software:** sistema operativo, versión y dependencias.
- **Organización:** cantidad de usuarios y permisos.
- **Datos:** copias de seguridad, privacidad y normativa aplicable (por ejemplo RGPD).

```text
Elección = necesidades + presupuesto + compatibilidad + seguridad
```

> [!TIP]
> Una suite gratuita puede ser adecuada para una oficina pequeña, pero una solución empresarial puede compensar por colaboración, soporte y gestión.

**Repaso:** ¿Qué significa TCO? **Coste total de propiedad, incluyendo gastos posteriores a la compra.**

# Correo y mensajería electrónica

El correo permite intercambiar mensajes y archivos mediante Internet. Un **cliente de correo** sirve para redactar, enviar, consultar y organizar mensajes.

## Clientes
| Tipo | Ejemplo | Característica |
|---|---|---|
| Escritorio | Thunderbird, Outlook | Aplicación instalada |
| Web | Gmail web, Outlook.com | Acceso desde el navegador |

## Protocolos de correo
| Protocolo | ¿Qué hace? |
|---|---|
| SMTP | Envía y transfiere mensajes |
| IMAP | Consulta y sincroniza mensajes entre dispositivos |
| POP3 | Descarga los mensajes al cliente |

## Destinatarios
- **Para:** destinatario principal.
- **CC (con copia):** copia visible para los destinatarios.
- **CCO (con copia oculta):** los demás destinatarios no ven las direcciones incluidas en CCO.

```text
Para: profesor@ejemplo.test
CC: equipo@ejemplo.test
CCO: contacto@ejemplo.test
Asunto: Entrega de práctica
```

## Mensajería instantánea
Servicios como Teams o Slack facilitan chats, grupos, llamadas y comunicación rápida en organizaciones.

> [!WARNING]
> Antes de enviar a muchas personas que no se conocen, considera utilizar CCO para no revelar sus direcciones de correo entre sí.

**Repaso:** ¿Qué protocolo usarías para sincronizar correo en el móvil y el ordenador? **IMAP.**

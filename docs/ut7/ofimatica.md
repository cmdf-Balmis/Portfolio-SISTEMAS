# Herramientas ofimáticas y documentación

La **ofimática** permite redactar documentos, gestionar datos, preparar presentaciones y colaborar.

## Microsoft Office y LibreOffice
| Uso | Microsoft | LibreOffice |
|---|---|---|
| Texto | Word (`.docx`) | Writer (`.odt`) |
| Hoja de cálculo | Excel (`.xlsx`) | Calc (`.ods`) |
| Presentaciones | PowerPoint (`.pptx`) | Impress (`.odp`) |

Microsoft Office suele comercializarse mediante licencia o suscripción; LibreOffice es una suite libre y gratuita. Ambos pueden abrir varios formatos comunes, **pero la compatibilidad en documentos complejos no es perfecta**.

## Editor de texto frente a procesador de textos
- **Editor de texto:** archivos planos (`.txt`, `.md`, código). Ejemplos: VS Code, Notepad++.
- **Procesador de textos:** documentos con estilos, tablas, márgenes e imágenes (Word, Writer).

## Markdown
Markdown es un lenguaje de marcado ligero que utiliza símbolos para añadir estructura al texto. Muy habitual en archivos `README.md` y documentación técnica.

```markdown
# Título
## Apartado
**Negrita**
- Elemento de una lista
[Enlace](https://example.com)
```

> [!TIP]
> Docsify transforma nuestros archivos Markdown en una web de documentación sin que tengamos que escribir una página HTML por cada apartado.

**Repaso:** ¿Qué aplicación de LibreOffice equivale a PowerPoint? **Impress.**

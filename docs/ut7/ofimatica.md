# Herramientas ofimáticas

## ¿Qué es la ofimática?

La ofimática incluye las aplicaciones que permiten
crear documentos, hojas de cálculo y presentaciones.

## Comparación de herramientas

| Microsoft Office | LibreOffice | Función |
|---|---|---|
| Word | Writer | Documentos |
| Excel | Calc | Hojas de cálculo |
| PowerPoint | Impress | Presentaciones |

## Editores de texto y Markdown

Los editores de texto permiten trabajar con archivos
de texto plano.

Markdown es un lenguaje de marcado ligero que
utiliza símbolos para organizar documentos.

## Ejemplo de código Markdown

```markdown
# Mi documento

## Introducción

**Esto está en negrita.**

- Primer punto
- Segundo punto
```

> [!TIP]
> Markdown es muy útil para crear documentación
> técnica y archivos README en GitHub.
